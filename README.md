# zoe-website

Personal website for Zoe Higgins, Engineering Manager.

Built with [React](https://react.dev/) + [Vite](https://vite.dev/). The design is deliberately plain — minimal colour, a serif font, and no animations.

## Vandalism tool

Click the **✏️ Vandalise** button in the bottom-right corner to enter drawing mode. A toolbar appears with colour swatches and brush sizes. Draw freely on the page. Click **Clear** to wipe the canvas or **Done** (or the toggle button again) to exit drawing mode. Drawings are session-only and disappear on page refresh.

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
npm run preview  # preview production build
npm run lint     # ESLint
npm test         # Vitest unit tests
```
